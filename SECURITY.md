# Security

Do not open a public issue for a suspected vulnerability.

Follow the [Meme Search security policy](https://github.com/neonwatty/meme-search/security/policy)
and identify this repository as the affected integration. Remove credentials,
private images, database contents, hostnames, and personal filesystem paths from
the report.

This integration is experimental. Its existence does not expand the core
project's supported loopback-only deployment boundary.
